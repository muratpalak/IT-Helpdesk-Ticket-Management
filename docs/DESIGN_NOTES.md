# Glass UI visual design notes

Design direction: minimal sculpted control surface inspired by the supplied capsule references. Three raised ceramic capsules in the hero are **working actions**, not ornamental screenshots:

1. **New request** opens ticket creation.
2. **In progress** opens the ticket list filtered to currently in-progress tickets.
3. **Completed** opens the ticket list filtered to resolved and closed tickets.

The app also includes a segmented control for `All requests / Active / Completed` and contextual status, priority, and SLA badges. Responsive breakpoints cover desktop, tablets and mobile. All visual assets are CSS and inline SVG; no externally hosted fonts or images are required.
